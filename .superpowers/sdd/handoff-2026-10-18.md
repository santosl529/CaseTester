## Gotchas met this session

- Never `cd` into the main checkout from a worktree session — use `git -C` and absolute paths. zsh doesn't word-split a command held in a variable (`$G merge …` fails).
- Python heredocs editing TS: `"\b"` in a normal Python string is a backspace — use raw strings (one slipped into `stream-turn.ts` and was caught by a test).
- The batch launcher's children load `--env-file=.env.local` relative to cwd: a worktree needs the gitignored symlink. At most 10 personas a wave; a failed wave leaves a manifest — remove the empty batch dir before relaunching. Batch runs land in the worktree's own `Case Interview Runs/` — copy them to the main checkout's folder (where the corpus lives) before replaying.
- Cartesia renders via the demo scripts sometimes take minutes per line — run them in the background.
- The main checkout's untracked `Case Interview Runs/` files can block a merge when a branch tracks the same paths: compare, move aside (don't delete), merge, verify.
